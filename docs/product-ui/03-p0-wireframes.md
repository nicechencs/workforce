# Workforce P0 页面线框规范

**版本：** V0.1 Draft  
**状态：** Ready for visual design  
**日期：** 2026-09-10  
**修订：** 侧栏按 [IA §2](01-information-architecture.md) 含 P1「运行记录」「工作流」；并增加只读工作流页线框（模板 / 版本 / 结构化步骤，无画布）。标题中的 P0 指主工作区切片，不隐藏 P1 一级导航。

## 1. 全局框架

桌面端采用左侧一级导航、顶部上下文区和主工作区。首屏不放营销内容。

侧栏成员以 [页面信息架构 §2](01-information-architecture.md) 为准：`P0`/`P1` 是切片深度，P1「运行记录」「工作流」必须画在左侧栏。§2–§6 与 §8 细化 P0 主工作区；§7 是 P1 工作流只读页（模板 / 版本 / 结构化步骤）。

```text
┌──────────────┬─────────────────────────────────────────────┐
│ Workforce    │ 当前 Workspace / 页面          通知  新建   │
│              ├─────────────────────────────────────────────┤
│ 工作台       │                                             │
│ 项目         │                主工作区                     │
│ AI 团队      │                                             │
│ 执行节点     │                                             │
│ 审批中心     │                                             │
│ 运行记录     │                                             │
│ 工作流       │                                             │
│ 设置         │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

响应式规则：

- 宽屏：固定侧栏，主内容最多两列。
- 窄屏：侧栏折叠，关键操作保留在顶部。
- 移动宽度只保证监控和审批，不作为 V0.1 正式移动端。

## 7. 工作流（P1，只读）

主工作区按 [IA §6.2](01-information-architecture.md)：模板、不可变版本、结构化步骤。不是画布编辑器，无创建/保存。

```text
┌────────────────────────────────────────────────────────────┐
│ 工作流                                                     │

├────────────────────────────────────────────────────────────┤

│ 3. 整合     交付 · stable Node ID                          │
│ 4. 审查     任务 · reviewer                                │
│ 5. 验收     审批 · gate artifact                           │

```

## 8. 新建项目流程

采用分步侧边面板或独立流程页：

1. 项目目标
2. WorkspaceBinding
3. AI Team
4. Task 计划与验收条件
5. 执行位置策略
6. 权限、预算和最终确认

V0.1 的执行位置默认值为“本机”；未来存在远程节点时可选择自动调度或指定节点。

## 9. 视觉基线

- 浅色界面，冷灰页面背景和白色内容卡片。
- 单一蓝色作为主要操作和选中状态，不使用蓝紫渐变。
- 绿色表示健康/完成，橙色表示等待/注意，红色表示失败/危险。
- 正文不小于 16px；常用标签不小于 14px。
- 边框、阴影和圆角克制，优先保证高密度信息的可读性。
- Node、Worker、Runtime 和 Run 使用不同文字标签与图标，不依赖颜色区分。
